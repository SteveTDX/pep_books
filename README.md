# 人教数字教材下载器（义务教育 · 五四学制）

> ⚠️ **声明：本项目仅供个人学习与研究使用**（personal research only）。请尊重人教社数字教材版权，严禁将下载内容用于商业用途或再分发；请于下载后 24 小时内删除，并以购买正版纸质教材为准。

访问 [jc.pep.com.cn](https://jc.pep.com.cn/)（人民教育出版社数字教材网），抓取 **义务教育（五四学制）** 全部分册书目，在本地网页上勾选后，由 Selenium 打开真实电子书阅读器**逐页翻页**抓取页面高清 jpg（点击间隔随机抖动），并自动按页序合成 PDF。

## 功能特性

- **书目抓取**：Selenium 访问首页 → 激活 text 为“义务教育（五四学制）”的 `li` → 依据 `ul.el-pager` 分页器逐页遍历 `div.page_pc_btm_book_body`，取第一个 `class="imga"` 的 `<a>` 的 `title`（书名）与 `href`（地址前段），建立 `{书名: href}` 字典并缓存到 `books.json`。
- **本地 Web 界面**（Flask）：
  - 逐行显示书名，行左侧带多选框；
  - 窗体左上角“全选 / 取消全选”切换按钮（初始为“全选”）；
  - 窗体右上角**悬浮**“下载选中”按钮。
- **翻页下载**：每本书打开 `<href>mobile/index.html` 阅读器，读取 `id="currentPageIndexTextField"` 输入框 value（形如 `1/148`）得到总页数 `maxPageCount`，随后循环点击“下一页”控件翻页、用 canvas 提取阅读器已加载的页面图片（`img → drawImage → toDataURL`，同源画布），保存到 `jpg/<书名>/NNN.jpg`；点击间隔在 1.2~2.8 秒间随机抖动，模拟真人阅读节奏。
- **自动合成 PDF**：全部下载完成后，把每本书的 jpg 按页序合成为 `pdf/<书名>.pdf`（img2pdf 无损嵌入优先，Pillow 兜底）。
- **行内进度条**：
  - 下载 jpg 时，对应书名行**蓝色底纹**从左向右生长，铺满整行即 100%；
  - 合成 PDF 时改为**绿色底纹**，同样方式生长。
- **断点续传**：已下载且校验有效的页 jpg 自动跳过；中断后重新勾选下载即可续传。

## 反爬设计（实测要点）

站点（`book.pep.com.cn`）前端部署阿里云 WAF，本项目针对性处理：

| 现象 | 对策 |
| --- | --- |
| 直接访问书本地址被重定向回首页 | 先打开 `jc.pep.com.cn` 首页，再通过页面内 `<a>` 点击跳转（携带 Referer） |
| 对图片地址发起 fetch/xhr 返回滑块验证页 | 不发额外图片请求，只用 canvas 提取阅读器自身已加载的图片 |
| 自动化特征导致人工滑动滑块也报错 | 浏览器统一做隐身处理（隐藏 `navigator.webdriver`、禁用 AutomationControlled 等） |
| 无头浏览器被滑块验证拦截 | 自动在同一持久化配置上重开**有头窗口**，人工滑动一次后继续；`chrome_profile/` 会记住验证信任状态 |

## 环境要求

- Python 3.9+
- Chrome 浏览器（未安装时自动回退 Edge；Selenium Manager 自动下载驱动）
- 网络可访问 `jc.pep.com.cn` 与 `book.pep.com.cn`

## 安装

```bash
pip install -r requirements.txt
```

> 若镜像源缺少某个包（如 selenium / img2pdf），可改用官方源：
> `pip install selenium --index-url https://pypi.org/simple`，
> 网络不通时可加本机代理：`--proxy http://127.0.0.1:7890`。

## 使用

```bash
python app.py
```

启动时若 `books.json` 不存在会先抓取书目（约 1 分钟，有逐页日志），随后打开：

> http://127.0.0.1:5000

在网页中勾选书目 → 点击右上角“下载选中”，即可在页面观察每本书的下载/合成进度（下载采用真实翻页方式，约 1~2 秒/页，请耐心等待）。产物：

- `jpg/<书名>/001.jpg … NNN.jpg` —— 各册页面图片（1274×1800 高清）
- `pdf/<书名>.pdf` —— 合成的电子书

若运行中弹出滑块验证窗口，手动滑动一次即可，任务会自动继续。

### 命令行参数

| 参数 | 说明 |
| --- | --- |
| `--port 5000` | Web 服务端口（默认 5000） |
| `--host 127.0.0.1` | 监听地址 |
| `--force-scrape` | 忽略 `books.json` 缓存，重新抓取书目 |
| `--visible` | 显示浏览器窗口（调试用；正常下载为无头模式） |
| `--cache PATH` | 指定书目缓存文件路径 |

## 工作流程

```
jc.pep.com.cn 首页
      │ 点击 li「义务教育（五四学制）」
      ▼
ul.el-pager 得到总页数 ──逐页──▶ {书名: href} 字典（books.json）
      │
      ▼
Flask 网页（多选 + 全选 + 悬浮下载按钮）
      │ 点击“下载选中”（逐本串行）
      ▼
jc 首页 → <a> 点击跳转 → <href>mobile/index.html 阅读器
      │ #currentPageIndexTextField.value="1/N" ──▶ maxPageCount=N
      ▼
循环：canvas 提取已加载页图 → 点击“下一页”（间隔随机抖动）
      ──▶ jpg/<书名>/NNN.jpg            （行内蓝条进度）
      │ 全部下载完成
      ▼
jpg/<书名>/*.jpg 按页序合成 ──▶ pdf/<书名>.pdf   （行内绿条进度）
```

## 目录结构

```
pep_books/
├── app.py               # Flask 入口 + 后台任务调度（串行下载 → 并行合成 PDF）
├── browser.py           # Selenium 浏览器统一创建（去自动化特征、持久化配置）
├── scraper.py           # 书目清单抓取（分类激活 + 分页遍历）
├── downloader.py        # 阅读器翻页下载（canvas 提取、随机抖动、断点续传、滑块应对）
├── pdf_maker.py         # jpg → PDF（img2pdf 优先，Pillow 兜底，合成前校验）
├── templates/index.html # 前端页面（多选/全选/悬浮下载/进度底纹/验证横幅）
├── requirements.txt
├── books.json           # 运行时生成的书目缓存
├── chrome_profile/      # 运行时生成的浏览器持久化配置（保存验证信任状态）
├── jpg/                 # 运行时生成：每本书一个子文件夹
└── pdf/                 # 运行时生成：合成后的 PDF
```

## 常见问题

- **首次运行卡在“正在抓取书目”**：站点结构变化或网络受限，可加 `--visible` 观察浏览器窗口排查；成功抓取后结果会缓存，之后启动秒开。
- **弹出滑块验证窗口**：正常反爬流程，人工滑动一次即可；验证状态记录在 `chrome_profile/`，通常不会反复出现。若同一窗口滑动后仍反复出现滑块，说明该 IP 被临时限流，稍等几分钟再试。
- **某本书显示“✗ 失败”**：鼠标悬停状态文字可看原因；多为单页网络超时或触发限流，重新勾选该书再点下载即可续传（已下载的页会跳过）。
- **下载速度**：约 1~2 秒/页（含随机抖动），一本 150 页的书约 3~5 分钟；多本书按顺序逐本下载。
